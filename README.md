🌤️ Weather Forecast App
A modern and user-friendly weather forecasting web app built using HTML, CSS, and JavaScript, powered by the Open-Meteo API. It provides real-time weather updates including:

🌡️ Temperature (current, max, min)

🌬️ Wind speed and direction

💧 Humidity and real feel

☀️ UV Index, Sunrise & Sunset

🌫️ Air Quality Index (AQI)

📍 City-based weather search

🎨 Animated UI with weather emojis
